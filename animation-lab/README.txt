LEM.CO Animation Lab — starter folder

This is a separate Vite + React app. It does not modify the existing Drawing Lab or the root LEM.CO Lab website.

Folder setup:
1. Copy the animation-lab folder into your LEM.CO Lab project directory.
2. Open a terminal in animation-lab.
3. Run: npm install
4. Run: npm run dev
5. Open the local URL printed by Vite.

To verify a production build, run: npm run build

The current App.jsx and index.css are the initial Animation Lab draft. Some animation features and panel layout work remain to be completed and tested.
